# 拼豆像素画助手（PingDou）

把任意图片转换为 24×24 像素画，按游戏固定 40 色色板配色，
再通过图像识别 + 模拟点击在游戏「涂鸦玩法」中自动落格填色。

> ⚠️ 仅供个人学习研究使用。请遵守游戏平台用户协议与内容规范，
> 不要使用本工具发布违反国家法律法规或平台规定的内容。

## 功能特性

- 🖼 导入任意图片 → LANCZOS 降采样为 24×24 → CIEDE2000 最近邻匹配游戏色板
- 🎨 色块清单：自动统计所需颜色与用量，色差过大的格子红框警示
- 📐 分辨率自适应：不假设色板位置，任意窗口大小均可自动定位画布与色板
- 🎯 全自动落格：先填当前可见颜料 → 自动滚动色板继续 → 到底自动停止
- 🛡 安全机制：ESC 全局热键 / 停止按钮 / 鼠标推角落紧急中断

## 快速开始（打包版）

1. 双击 `PingDou.exe`（会弹出 UAC 提权窗口，点"是"——游戏以管理员权限运行，工具必须同权限）
2. ① 导入图片 → 预览 24×24 效果与所需色块
3. ② 框选游戏区域（含画布和色板）
4. ③ 检测界面 → 核对叠加图：绿框=画布、黄圈=色块
5. ④ 开始填充 → 3 秒倒计时后自动执行

## 工具脚本

| 脚本 | 用途 |
|---|---|
| `tools/extract_palette.py` | 游戏更新色板后，从色板截图重新提取 40 色 |
| `tools/selftest.py` | 离线自检：画布定位 / 色板扫描 / 图像管线 |
| `tools/scroll_test.py` | 滚动标定：量化游戏对滚轮事件的响应 |

## 常见问题

- **点击不生效**：必须以管理员权限运行本程序（游戏同权限，UIPI 拦截低权限输入）
- **滚动距离极小**：游戏对 pyautogui.scroll 的小增量事件会吞掉，本工具已改用标准 WHEEL_DELTA(120) 事件逐刻度发送
- **中间留白横带**：默认勾选"跳过纯白格"（画布默认白底），若原图中间有纯白区域会跳过不填，取消勾选即可
- 配置保存在 exe 旁的 `config.json`（阈值、滚动步长、点击间隔等）

## 目录结构

```
main.py                    # 入口
config.py                  # 配置与路径（打包/开发双模式）
core/                      # 颜色匹配、色板扫描、画布定位、落格线程
ui/                        # 主窗口、预览、色块清单、区域框选
utils/                     # 截图(mss)、输入(pyautogui+ctypes)、OpenCV 工具
tools/                     # 色板提取、自检、滚动标定
known_palette.json         # 游戏 40 色色板（10 行 × 4 列）
```
